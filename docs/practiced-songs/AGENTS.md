# Duolingo Music 实机练习规程

本目录是一曲一档的实机证据库。

## 工作方式：小步快跑

每一步只做一小件事，做完就停下来报告结果，等用户确认再走下一步。一步的范围由用户给出，照原样执行：用户说"弹当前屏幕"，就只弹当前屏幕并停手；"预取下一小节"是弹奏中的读谱手段，不是连续弹整首的许可。

每一步的结果都要有画面证据才算数：设备 ACK、脚本退出码、"没有报错"都不等于弹对了。

## 完成标准

- 终极挑战只有在结算页明确显示三颗星时才算完成；进入结算页、播放完毕或一颗星都不算。
- 保存结算截图，记录分数、音高、节奏和经验值。证据链接使用仓库相对路径。
- 每首曲子一个 Markdown 文件；曲谱事实只放在本目录对应曲目文件。

## 主流程：逐屏实时演奏

一屏显示约两个小节。每一步弹当前一屏，停手，验证。

1. **读屏**。截图并识谱，确认前台是钢琴页、五线谱可见：

   ```sh
   python3 scripts/duolingo-read-screen-notes.py --serial "$serial"
   ```

   完成条件：每个音符都有音名、时值和琴键坐标，没有 `⚠ 未标注键`。

2. **弹奏**：

   ```sh
   python3 scripts/duolingo-rehearse-song.py rehearse --serial "$serial" \
     --output outputs/<run> --beat-ms <本曲实测值> \
     --save-frames --save-every 2
   ```

   完成条件：日志出现 `grid locked`（报出每小节拍数）、`anchored on the start note`、`reached the end of the first playable measure`。

3. **验证**。用 `outputs/<run>/frames/` 读判定文字区，逐音记录判定。完成条件：每个调度音都有对应的判定，或能说明为什么没有。

## 核心规则

**键位从屏幕读，不查表。** 每次运行由 `duolingo_keyboard_detect.py` 检测：黑键 3 个一组骑在 F-G-A-B 上、2 个一组骑在 C-D-E 上，字母由此确定；八度来自键上的箭头（无箭头 = 4，↑ = 5，↓ = 3）；同一组白键必定同八度，所以被高亮遮住标签的键可以从同组兄弟推出。Duolingo 只给本曲用到的键印标签，整组都没标签的键不进表，要按它就报错。`duolingo_keyboard_profiles.py` 只是 `--keyboard-profile` 逃生通道。

**拍位以小节线为锚，不以符头为锚。** 符头画在其拍位右侧约 0.3 拍处（排版左边距），拿第一个符头当零点会让全曲偏移。拍位 = (音符 x − 同一帧的小节线相位) ÷ 每拍像素 − δ；δ 取非负且不能让小节末音越过下一条小节线的最小值。音符的 x 和小节线相位必须来自同一帧。

**拍号从谱面推，不写死。** 每小节拍数 = 小节线间距 ÷（相邻音符间距 ÷ 时值）取整。已见过 4/4（间距 576px）和 3/4（间距 432px），两者每拍都是 144px。

**停手点从谱面推。** 停在「起奏音所在小节之后，第一个含音符的小节」的末尾。正常屏自动等于 2 小节；开头休止很长时自动往后等。

**账本要多次读数佐证。** 同一个音至少被读到 2 次才弹（`--min-sightings`）；同一拍位出现多个音高时取读数最多的。单帧的误读会整体错位半拍或读错音高，只出现一两次。

**颜色不当判据。** 判定文字、命中符头、琴键高亮的颜色随课程和结果变化（绿、粉、灰、淡紫都出现过）。检测反馈用饱和度，读判定用文字内容。

**读判定取按键后 400–800ms 的帧。** 判定文字约在按键后 460ms 才出现；更早的帧是空白，不代表没判到。

## 已知未解决的问题

按严重程度排：

1. **一拍时长测不准到整曲所需的精度。** 整曲连弹需要准到约 0.5%；同一首 3/4 曲子测出过 823ms 和 803ms（差 2.7%），逐屏短跑两者都能全中，所以短跑成功不能证明拍长准。fullsong-03 用 803 从头连弹，第 11 拍起就判"要停顿"（按早）。当前逐屏演奏用 `--beat-ms` 手动传入实测值。
2. **长时间跟踪会丢锁。** 同一次整曲运行在第 26 拍处小节线相位跳变约 4 拍，之后定位全乱。
3. **起奏音不进连击。** 每一屏的连击数都等于调度音数，起奏音从不计入，每屏固定少 1 个音。

`--play-to-end` 和 `--refine-tempo` 用于整曲实验，在问题 1、2 解决前不作为正式演奏手段。

## 曲目文件最低字段

课程位置与挑战类型、标题与版本、谱号、拍号、调号和临时升降号、音域、琴键坐标、逐小节事件、纯音符顺序、所有休止符、时值统计、所用拍长、完成成绩，以及能复核结论的相对证据链接。
