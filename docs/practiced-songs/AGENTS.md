# Duolingo Music 实机练习规程

本目录是一曲一档的曲谱与演奏经验档案。

## 工作方式：小步快跑

每一步只做用户授权的范围：用户说"弹当前屏幕"，就只弹当前屏幕并停手；用户明确要求连续弹完整曲时，允许一次运行跨屏直到曲终。每次运行后报告画面判定；"预取下一小节"只是弹奏中的读谱手段。

每一步的结果都要有画面证据才算数：设备 ACK、脚本退出码、"没有报错"都不等于弹对了。

## 完成标准

- 终极挑战只有在结算页明确显示三颗星时才算完成；进入结算页、播放完毕或一颗星都不算。
- 核对结算画面，记录分数、音高、节奏和经验值。
- 每首曲子一个 Markdown 文件；曲谱事实只放在本目录对应曲目文件。

## 资料保留

- 曲目 Markdown 保留完整曲谱、完成成绩、所用拍长、琴键坐标和可复用的演奏经验。
- 截图、录屏、音符账本、按键日志和相位文件用于当次验证，不作为长期归档附件；曲目 Markdown 不引用这些实验文件。
- 完成验证并将结论写入曲目档案后，清理对应的临时输出。自动化测试需要的最小回归样例放在 `tests/fixtures/`，测试直接读取这些样例。

## 主流程：逐屏实时演奏

一屏显示约两个小节。每一步弹当前一屏，停手，验证。

1. **读屏**。截图并识谱，确认前台是钢琴页、五线谱可见：

   ```sh
   python3 scripts/duolingo-read-screen-notes.py --serial "$serial"
   ```

   完成条件：每个音符都有音名、时值和琴键坐标，没有 `⚠ 未标注键`。

2. **弹奏**：

   ```sh
   python3 scripts/duolingo-rehearse-song.py rehearse --serial "$serial" \
     --output /tmp/duolingo-<run> --beat-ms <本曲实测值> \
     --timing-offset-ms <当前设备和挑战实测值> \
     --save-frames --save-every 2
   ```

   完成条件：日志出现 `grid locked`（报出每小节拍数）、`anchored on the start note`、`reached the end of the first playable measure`。

3. **验证**。用 `/tmp/duolingo-<run>/frames/` 读判定文字区，逐音记录判定。完成条件：每个调度音都有对应的判定，或能说明为什么没有。

## 连续演奏

用户授权弹整首时，使用同一读屏和输入会话连续跨屏：

```sh
python3 scripts/duolingo-rehearse-song.py continuous --serial "$serial" \
  --output /tmp/duolingo-<run> --beat-ms <本曲实测值> \
  --save-frames --save-every 6
```

`--beat-ms` 是本曲测得的起始估计；运行中由当前谱面的小节线滚动持续修正。连续模式默认用当前会话测得的按键高亮延迟对齐判定线，`--timing-offset-ms` 仅是视觉时钟未就绪时的显式回退。拍号、琴键、音符、时值与停止状态均从当前画面读取；首次可靠读屏锁定整曲的排版偏移，后续读屏只做一致性检查。若脚本因失锁、读谱迟到或画面停住而停手，记录原因与判定画面；画面停住可能是正常曲终，必须以结算页核实。连续模式的完成条件是三颗星结算、末音与抬键证据、无多余尾音输入。

## 核心规则

**键位从屏幕读，不查表。** 每次运行由 `duolingo_keyboard_detect.py` 检测：黑键 3 个一组骑在 F-G-A-B 上、2 个一组骑在 C-D-E 上，字母由此确定；八度来自键上的箭头（无箭头 = 4，↑ = 5，↓ = 3）；同一组白键必定同八度，所以被高亮遮住标签的键可以从同组兄弟推出。Duolingo 只给本曲用到的键印标签，整组都没标签的键不进表，要按它就报错。`duolingo_keyboard_profiles.py` 只是 `--keyboard-profile` 逃生通道。

**拍位以小节线为锚，不以符头为锚。** 符头画在其拍位右侧约 0.3 拍处（排版左边距），拿第一个符头当零点会让全曲偏移。拍位 = (音符 x − 同一帧的小节线相位) ÷ 每拍像素 − δ；δ 取非负且不能让小节末音越过下一条小节线的最小值。音符的 x 和小节线相位必须来自同一帧。

**拍号从谱面推，不写死。** 每小节拍数 = 小节线间距 ÷（相邻音符间距 ÷ 时值）取整。已见过 4/4（间距 576px）和 3/4（间距 432px），两者每拍都是 144px。

**停手点按模式区分。** 逐屏模式停在「起奏音所在小节之后，第一个含音符的小节」的末尾；连续模式跨屏读谱，直到谱面停止滚动或发生失锁/迟到等安全停手条件，并核对结算页和尾音。

**账本要多次读数佐证。** 同一个音至少被读到 2 次才弹（`--min-sightings`）；同一拍位出现多个音高时取读数最多的。单帧的误读会整体错位半拍或读错音高，只出现一两次。

**逐屏记录合并时先对齐重叠。** 逐屏模式的下一个提示可能位于上一屏开始后 4 拍，也可能位于 8 拍；发生失误时还可能回退。使用 `scripts/duolingo-merge-rehearsal-screens.py` 从相邻运行共同看到的音符推断位移。重复乐句导致两个候选同样合理时，结合保存的停顿画面指定经核实的位移；不能按屏号固定加 8 拍或把重叠音符重复送入连续模式。

**颜色不当判据。** 判定文字、命中符头、琴键高亮的颜色随课程和结果变化（绿、粉、灰、淡紫都出现过）。检测反馈用饱和度，读判定用文字内容。

**读判定取按键后 400–800ms 的帧。** 判定文字约在按键后 460ms 才出现；更早的帧是空白，不代表没判到。

## 当前边界

- `--beat-ms` 仍需为当前曲子提供实测起始估计；视觉时钟随后从本曲滚动谱面持续校准。未知曲目不能沿用上一首的数值。
- 读谱需要至少两次一致观察。识谱处理落后、丢失小节线或音符太晚出现时，连续模式安全停手，并以结算画面区分曲终与失败。
- 目前连续运行保存抽样 PNG、逐帧时间、相位、音符账本和按键日志；不自动保存完整 H.264/PTS/MP4。需要完整视频时，应另行开启已验证的录制流程，不能把抽样帧称作完整录屏。
- 起奏音用于启动滚动谱面，不计入连击。核对音符数量时分别数起奏音、后续判定音和 DOWN/UP 对。

## 曲目文件最低字段

课程位置与挑战类型、标题与版本、谱号、拍号、调号和临时升降号、音域、琴键坐标、逐小节事件、纯音符顺序、所有休止符、时值统计、所用拍长、完成成绩及可复用的演奏经验。
