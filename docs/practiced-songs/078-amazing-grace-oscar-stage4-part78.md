## 琴键与修正过程

屏幕触点约为 A4 `(416,603)`、B4 `(537,603)`、C♯5 `(734,466)`、D5 `(795,603)`、E5 `(916,603)`、F♯5 `(1114,466)`、G♯5 `(1234,466)`、A5 `(1295,603)`；坐标以横屏 1612×720 为准。

首次合并把第 3 拍 A5 误作 F♯5；第一轮录像显示实际是高音 A5。第二轮虽改正该音，却把第二屏起点接到了全曲第 5 拍，实际与第一屏第 3 拍的 A5 重叠；因此漏掉第 5.5 拍 E5，并使后续音符整体错位。把第二屏的局部 beat 0 对齐到全曲 beat 3 后，验证了谱面与节拍。
