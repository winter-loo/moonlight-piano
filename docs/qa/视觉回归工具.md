# 视觉回归工具

`scripts/visual-diff.mjs` 用于客观比较设计参考图与浏览器实现截图，减少前端实现仅凭主观观察得出“已经一致”的风险。工具不会替代人工设计评审；它负责暴露位置、颜色、字体渲染和尺寸造成的像素差异。

## 使用前提

两张图片必须具有完全相同的像素尺寸。浏览器截图应使用参考图对应的视口、设备像素比和页面状态；尺寸不一致时工具直接报错，避免缩放掩盖布局问题。

## 基础命令

```bash
npm run visual:diff -- reference.png implementation.png
```

默认输出到 `work/visual-diff/`。该目录属于本地工作产物，不提交 Git。

## 自动验收

```bash
npm run visual:diff -- reference.png implementation.png \
  --output-dir work/visual-diff/b1-02 \
  --threshold 12 \
  --min-within-tolerance 97 \
  --max-mae 4
```

- `--threshold`：单个像素四通道平均误差大于该值时，计为感知差异像素；默认 `12`。
- `--min-within-tolerance`：容差内像素比例的最低要求，范围 `0–100`。
- `--max-mae`：平均通道绝对误差的上限，范围 `0–255`。
- 任一验收条件不满足时，进程以退出码 `2` 结束，可直接用于 CI 阻断。

阈值必须针对同一种页面和截图环境建立基线。字体栅格化、操作系统和浏览器版本不同会产生可见性很低但数量较多的像素差异，因此不要跨环境沿用未经验证的阈值。

## 输出产物

| 文件 | 用途 |
|---|---|
| `metrics.json` | 机器可读指标、验收条件与最终结果 |
| `comparison.png` | 左侧参考图、右侧实现图的并排对照 |
| `overlay.png` | 实现图以 50% 透明度覆盖参考图，检查偏移和轮廓 |
| `difference.png` | 两图逐像素差值 |
| `heatmap.png` | 强化差异区域，快速寻找问题集中位置 |

主要指标：

- `exactMatchPercent`：完全相同像素比例，通常只适用于同环境确定性截图。
- `withinTolerancePercent`：未超过感知阈值的像素比例，是主要视觉门槛。
- `meanAbsoluteChannelError`：全部 RGBA 通道的平均绝对误差。
- `rootMeanSquareChannelError`：对大误差更敏感，用于识别少量严重偏差。
- `maxChannelError`：最大单通道误差。

## 推荐工作流

1. 固定浏览器版本、视口、设备像素比、字体与页面状态。
2. 截取实现图，先运行工具生成五类产物。
3. 查看热力图定位问题，再用叠加图确认几何偏移。
4. 修正页面后重复截图和比较，保留最终 `metrics.json`。
5. 人工检查交互、动画、声音和教学正确性；这些不属于静态像素比较范围。
6. 只有最终参考、代表性状态和能证明结论的证据进入 `docs/qa/`。

## 当前限制

- 工具不负责启动浏览器或截图；截图自动化可在后续接入 Playwright。
- 工具只比较静态图片，不能判断动画时序、触控延迟和音画同步。
- 工具不会自动裁切或缩放图片；页面必须从源头在正确视口下捕获。
